# Custom Data Tool Case Study

This folder contains the public-facing one-page overview for the **Enrollment & Outpatient Visit Processing** custom data tool.

- [`Enrollment_Outpatient_Visit_Processing_Pipeline_One_Pager.pdf`](Enrollment_Outpatient_Visit_Processing_Pipeline_One_Pager.pdf)

The one-page overview is written for non-technical readers and emphasizes the client-facing value of the work: a recurring healthcare data-processing problem translated into a repeatable tool with explicit business rules, QA checks, and standardized outputs.

The repository README and pipeline source code provide the underlying technical detail.

No raw patient-level data are included in this repository.
